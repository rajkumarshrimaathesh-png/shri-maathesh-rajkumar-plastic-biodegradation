# Mealworm and polystyrene biodegradation research

An educational project summary from the 32nd National Children's Science Congress in Karaikal. The site documents observations about yellow mealworms, expanded polystyrene, and a small frass and plant comparison.

## View the site

GitHub Pages deploys this static page from `index.html` whenever it changes on `main`.

## Research limitations

The page distinguishes field observations from chemical findings, notes conflicts in the supplied source documents, and explains the limitations of a single plant per group. Student names are omitted. The project did not test frass for plastic residues or additives.
